Scriptovate

Project information

  • Category: AI-Powered Screenwriting & Story Development Web Platform
  • Frontend: Next.js 16, React 19, Redux Toolkit, Tailwind CSS
  • Backend: NestJS
  • Database: PostgreSQL
  • AI: OpenAI
  • Payments: Stripe

Scriptovate automates Hollywood-standard screenplay formatting in real time, including Scene Headings, Action, Dialogue, and Transitions — powered by AI and built for professional screenwriters.

  • Automated Hollywood-standard screenplay formatting in real time.
  • Dynamic Courier 12pt PDF export and film runtime estimation.
  • 3-Act and 5-Act emotional arc analysis.
  • OpenAI-powered screenplay analysis across 10 narrative dimensions.
  • Drag-and-drop corkboard, line-by-line script commenting & collaboration.
  • Stripe subscription plans with AI credit metering and tier-based access.
  • Modular NestJS REST APIs with JWT auth, role-based access control.
