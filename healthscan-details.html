HealthScan — AI-Powered Health & Nutrition App

Project information

  • Category: Mobile Application & AI
  • Framework: React Native & Expo
  • Backend: NestJS & PostgreSQL
  • AI Integration: OpenAI API (Vision & LLM)

HealthScan is a cross-platform mobile application built using Expo and TypeScript for food scanning, nutrition analysis, health scoring, risk assessment, pollutant analysis, and personalized health recommendations.

  • Formula-based score calculations across Health, Nutrition, and Pollutants.
  • Categorized insights across Needs, Overview, and Risks.
  • Modular NestJS REST APIs for authentication, profiles, surveys, and food scans.
  • OpenAI Vision API integration analyzing food photos and descriptions into structured JSON data.
